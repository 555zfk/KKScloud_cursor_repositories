# 交叉滚子轴承校核

关节输出端（交叉滚子环 / 减速器输出轴承）在径向力、轴向力、倾覆力矩联合作用下的校核。
公式出处：THK 交叉滚子环样本 515-1E
（<https://tech.thk.com/en/products/pdf_download.php?file=E_18_CrossRollerRing.pdf>）。

## 公式

三个载荷**不能各自比对，必须先合成为当量径向载荷**。

静等价径向载荷与静态安全系数：

```
P0 = X0·(Fr + 2M/dp) + Y0·Fa        X0 = 1, Y0 = 0.44
fs = C0 / P0
```

动等价径向载荷（寿命计算用）：

```
Pc = X·(Fr + 2M/dp) + Y·Fa
    Fa/(Fr + 2M/dp) ≤ 1.5  ->  X = 1,    Y = 0.45
    Fa/(Fr + 2M/dp) >  1.5  ->  X = 0.67, Y = 0.67
    Fr = 0 且 M = 0        ->  X = 0.67, Y = 0.67
L10 = (C/Pc)^(10/3) × 10^6  转
```

单一载荷极限（均为 fs=1，即滚子接触应力 4000 MPa 的损伤临界，**不是设计许用值**）：

```
静许用径向载荷 = C0
静许用轴向载荷 Fa0 = C0 / Y0 = C0 / 0.44
静许用倾覆力矩 M0  = C0 · dp / 2
```

单位注意：M 用 N·mm、dp 用 mm 时 P0 得到 N。若 M 以 N·m 记，需乘 1000。

## 安全系数要求

| fs | 条件 |
|---|---|
| ≥ 2 | THK 普通载荷下限 |
| ≥ 5 | THK 冲击载荷下限（机器人落地、起跳属此类） |
| ≥ 7 | THK 推荐值 |

低于 2 会在滚道留下永久压痕、破坏回转精度。评价时给出 fs 的中位、第 1 百分位、
最小值，以及 `fs<5` 和 `fs<2` 的时长占比，比只报一个最小值更能说明问题。

## 关键认识：dp 决定倾覆力矩的放大倍数

`2M/dp` 这一项等价于**力臂 dp/2**。交叉滚子环靠滚子节圆抗倾覆，dp 越小，
同样的倾覆力矩折算出的当量径向载荷越大。

以 dp = 84.7 mm 为例，每 1 N·m 倾覆力矩折算 23.6 N 当量径向载荷。
在机器人膝/髋这种倾覆力矩为轴向扭矩 2 倍以上的场合，
**P0 里倾覆项常占 80% 以上**，径向力和轴向力都是次要的。
这就是"倾覆能力先于电机扭矩成为瓶颈"的数学来源。

## 双轴承成对布置

弯矩由一对反向径向力承担，每只受力 `R = M / L`（L 为中心距），故：

```
许用弯矩 = C0 · L / fs
```

三个必须说清的结论：

1. **盈亏平衡跨距 L = dp/2**。低于这个跨距，两只轴承反而不如一只，纯属浪费。
2. **收益只是 L / (dp/2) 倍**，与跨距成正比而非成倍跃升。
   例：dp=84.7 的轴承取 L=60 mm，收益仅 60/42.35 = 1.42 倍，
   代价是零件翻倍、轴向尺寸从 5 mm 涨到 65 mm 以上。
3. **纯力偶假设偏保守约 15%**。两只轴承各自都有倾覆刚度，属静不定，
   弯矩会在力偶路径（刚度 ∝ L²/2）和局部弯矩路径（刚度 ∝ (dp/2)²）之间分流。
   两条路径刚度相等的跨距是 **L = dp/√2**；小于它则局部弯矩路径为主。
   实际轴与轴承座柔度通常更弱，会把载荷推向力偶路径，所以建议就按纯力偶取保守值。

成对布置时 P0 的构成：`P0 = M/L + Fr/2 + 0.44·Fa`
（径向力按跨中平分；载荷悬伸在跨外时须按实际几何重新分配；轴向力保守地由一只承担）。

## 设计建议

**成对使用交叉滚子环在原理上是浪费的**。交叉滚子环的价值就在于单只能抗倾覆；
若已有跨距空间，应配两只普通角接触/薄壁球轴承（更便宜、同轴度更易保证），
或把这段空间换成单只更宽断面的交叉滚子环——后者通常能带来数倍而非 1.4 倍的提升。

**同轴度是双轴承方案的隐藏风险**。两只都能抗倾覆的轴承串联属过约束布置，
座孔同轴度误差直接转化为内部附加载荷，两个座孔必须一次装夹镗出。
薄壁型（如 5 mm 断面）往往只有普通级精度、单一游隙、无密封、无安装孔，
须靠压紧法兰固定，对安装面平面度和螺栓拧紧顺序都敏感。

## 算例：RAU8005

THK RAU 系列小径 5 mm 超薄型，d80 × D91 × B5 mm，dp = 84.7 mm，
C = 3.05 kN，C0 = 5.43 kN，质量 50 g。

| 项目 | 数值 |
|---|---|
| 静许用径向载荷 | 5.43 kN |
| 静许用轴向载荷 | 12.34 kN |
| 静许用倾覆力矩（fs=1） | 230 N·m |
| 设计许用倾覆力矩 fs=2 / 5 / 7 | 115 / 46 / 33 N·m |
| 两只 @60 mm，fs=1 / 2 / 5 / 7 | 326 / 163 / 65 / 47 N·m |

用于某 54 kg 人形机器人膝关节（倾覆力矩 p99 = 220 N·m、峰值 584 N·m，
径向力 p99 = 1286 N、峰值 5073 N）的校核结果：

- 单只：fs 中位 4.18、第 1 百分位 0.86、最小 0.29，`fs<5` 占 66% 时长 → 不可用。
- 两只 @60 mm：fs 中位 6.16、第 1 百分位 1.30、最小 0.44，`fs<5` 占 26.5% → 仍不合格。
- 反推：p99 工况要达 fs=5，径向力与轴向力已占掉 68% 的 P0 预算，
  留给弯矩的余量对应跨距 637 mm → **加大跨距救不回来，必须换型号**。
- 同孔径换单只 RB8016（80×120×16，0.7 kg，dp=98，C0=42.1 kN）：
  静许用倾覆力矩 2063 N·m，p99 工况 fs = 7.2，一次合格。

这个算例说明：薄壁小断面型号适合手腕、头颈等倾覆力矩 ≲ 33 N·m（fs=7）的场合，
不适合承受落地冲击的膝/髋。
