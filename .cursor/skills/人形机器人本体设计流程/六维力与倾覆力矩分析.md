# 六维力与倾覆力矩分析

从仿真导出的关节六维力（wrench）中分离轴向扭矩与倾覆力矩，用于关节轴承、
减速器输出端与结构件的载荷输入。

## 数据字段（MuJoCo 导出的 npz 典型结构）

| 字段 | 形状 | 含义 |
|---|---|---|
| `time` | (N,) | 时间戳，据此反算采样率 |
| `joint_names` / `link_names` / `actuator_names` | (nj,) 等 | 名称表，用于按名取索引 |
| `joint_qpos` / `joint_qvel` | (N,nj,k) | 关节位置/速度，注意多自由度关节的 NaN 填充 |
| `joint_wrench_world` | (N,nj,6) | 关节六维内力，前 3 为力、后 3 为力矩，世界系表达 |
| `joint_axis_world` | (N,nj,3) | 关节回转轴，世界系 |
| `joint_quaternion_world_wxyz` | (N,nj,4) | 关节子体姿态，wxyz 顺序 |
| `link_external_wrench_world` | (N,nl,6) | 各 link 受到的外部力/力矩 |
| `actuator_output_torque` | (N,na) | 执行器实际输出扭矩（含限幅） |

字段名会因导出脚本而异，**先无条件打印全部键名、形状、dtype、min/max 再动手**。

## 必须先校准的三件事

### 1. 力矩的参考点是关节点还是世界原点

把力矩投影到关节轴，与该关节直接驱动的执行器扭矩比较相关性和 RMS 误差；
再换成"关于世界原点"的假设重算一次。相关性明显更高、RMS 误差明显更低的那个假设才是对的。
MuJoCo 的 `joint_wrench_world` 通常是**关于关节点**的。

### 2. 哪个求和才是真实地面反力

只把脚踝 link 的 Fz 相加会被闭链约束力污染（会出现大幅负值）。
判据是对整段时程求和后看最小值：

```python
Fz_all  = lew[:, :, 2].sum(axis=1)      # 全部 link 求和 -> 真实地面反力
Fz_feet = lew[:, iL, 2] + lew[:, iR, 2] # 只取脚踝 -> 可能被污染
```

`Fz_all` 应满足 min ≈ 0 且几乎没有负样本；`Fz_feet` 若出现数百牛的负值即为污染。
腾空判定、质量估算、相位划分都要用 `Fz_all`。

### 3. 整机质量

取真正静止的窗口（基座高度与竖直速度都接近常值），对 `Fz_all` 取中位数再除以 g。
不要用冲量法或含腾空段的窗口，会得到明显偏低或偏高的值。

## 倾覆力矩的提取

对回转关节，把力矩 M 沿回转轴 â 分解：

- 轴向扭矩 τ_axial = M · â
- 倾覆力矩 M_perp = |M − (M·â)â| = √(|M|² − τ_axial²)

`M_perp` 的模长**与坐标系选择无关**，只依赖轴方向，因此可以直接在世界系算，
不需要四元数。若还要判断倾覆方向，再用四元数转到关节子体系分解成两个正交分量。

同理分解力：轴向力 F_axial = F·â，径向力 F_rad = |F − F_axial·â|，
这两项用于输出轴承的等效动载荷与寿命校核。

## 可靠性差异（重要）

| 分量 | 可靠性 | 原因 |
|---|---|---|
| 垂直于轴的**倾覆力矩**与**径向力** | 可靠 | 纯约束反力，必须由轴承/减速器输出端全部承担 |
| 沿轴的**轴向扭矩** | 不可直接当电机需求用 | 还含关节阻尼、摩擦损耗、armature 惯量、限位约束力矩、跨关节闭链杆件力 |

轴向分量与执行器扭矩存在显著残差是正常现象，不是数据错误。
要得到电机扭矩需求就用 `actuator_output_torque`，不要用六维力的轴向投影。

## 校准自检

把回转轴用四元数转到关节子体系，若结果是接近 `(0,±1,0)` 这类坐标轴单位向量
且**标准差接近 0**，说明四元数与轴向数据自洽、变换实现正确。
标准差不为 0 说明四元数顺序（wxyz vs xyzw）或转置方向搞错了。

## 结果解读要点

- 倾覆力矩典型为轴向扭矩的 2～2.5 倍，须单列进模组设计需求。
- 力矩是关于关节点的。若轴承中心相对关节点有轴向偏置 d，需叠加 F_rad × d；
  在数千牛径向力下，每 10 mm 偏置就贡献数十 N·m，不可忽略。
- 单腿主导的动作（如 webster 空翻）左右峰值可以差 2 倍以上，
  但 p99 与 RMS 往往接近——峰值不对称不代表两侧要用不同规格。
- 跨关节的闭链杆件（achilles、腰部连杆）无法用标准 URDF 表达，
  这类模型必须用 MJCF 或在 Adams 里建约束，不要指望 URDF 往返不丢信息。
