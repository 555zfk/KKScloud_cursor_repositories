# 载荷可信性判据

用于判断 Isaac/MuJoCo 仿真导出的峰值扭矩、峰值弯矩、峰值接触力是否可作为设计载荷。
在统计 TN 散点、包络曲线、选型需求之前执行。

## 为什么必须做这一步

RL 训练出的策略会主动利用仿真的理想化条件（无背隙、无控制延迟、理想接触刚度、
执行器可瞬时换向），因此仿真峰值可能远高于实机。同时显式积分器在刚性接触下
会产生纯数值的力尖峰。两者混在同一条时程曲线里，靠肉眼看不出来。

## 判据一：峰值上升过程是否被解析

采样率决定了能分辨的最短事件。检查峰值前后的**单步跃升幅度**：

```python
dM = np.diff(x)                      # x 为待检查的载荷时程
jump = dM.max()                      # 最大单步跃升
rise_ratio = jump / x.max()          # 跃升占峰值的比例
```

- `rise_ratio > 0.5`：峰值在 1 个采样步内建立 → **欠解析**。真实峰值可能更高也可能更低，
  取决于未被采样到的接触过程，只能作定性参考。
- 同时统计事件宽度：以不同阈值切分连续段，看各段持续多少毫秒。
  若 >400 N·m 的事件只有 2～6 ms 宽，说明它是窄冲击而非持续载荷。

500 Hz 采样（2 ms）对落地冲击是不够的。要定量就需要把物理步长与采样率提到 2 kHz 以上，
并同时标定接触刚度与阻尼。

## 判据二：区分「接触冲击」与「控制跳变」

同一时刻查执行器输出扭矩的变化率：

```python
slew = np.abs(np.diff(tau)).max() / dt    # N·m/s
```

| 现象 | 判定 | 处理 |
|---|---|---|
| 执行器扭矩单步反向并撞限幅，slew 量级 >100 kN·m/s | 控制跳变假象。实机电流环无法实现这种阶跃 | 剔除，不作为设计载荷 |
| 执行器扭矩变化率正常（≲40 kN·m/s），但接触力/地面反力骤升 | 真实地面冲击，但幅值欠解析 | 保留作定性参考，不用于定量选型 |
| 载荷缓变，无骤升 | 可信 | 正常统计 |

另一个有力的旁证是同时刻的地面反力：若地面反力已归零（腾空）而关节载荷出现大峰值，
且关节合力很小，几乎必然是约束释放或策略输出跳变造成的数值假象。

## 判据三：用统计量代替极值

| 用途 | 统计量 | 理由 |
|---|---|---|
| 额定/选型 | **p99** | 排除欠解析尖峰，保留真实高载工况 |
| 轴承/减速器寿命（L10） | **立方平均** `(mean(x**3))**(1/3)` | 与滚动接触疲劳的三次方关系一致 |
| 热/连续能力 | RMS | 对应铜损与温升 |
| 结构强度定性摸底 | 峰值 | 仅作量级参考，需注明欠解析 |

同时给出**超限时长占比**（如 `(x>200).mean()`），它比单点峰值更能说明载荷严重程度。

## 报告写法

对每个关键峰值给出：时刻、幅值、事件宽度、单步跃升幅度、同时刻执行器扭矩与变化率、
同时刻地面反力（以体重 BW 归一）、所处相位（接触/腾空），以及成因判定。
逐条列出后再给结论，不要只报一个最大值。

## 需要复算时的处理

若某个峰值确实决定了选型档位，而它又被判为欠解析，可选：

1. 提高物理步长与采样率重跑同一策略，看峰值是否收敛。
2. 用 Adams 等变步长显式接触求解器复算同一冲击姿态，做交叉验证。
3. 接触刚度做 ±1 个数量级的敏感性扫描，取峰值随刚度变化的趋势而非单点值。

注意「峰值达不到就一定做不到这个动作」并不成立：策略可以通过改变落地姿态、
延长缓冲行程、用多关节协同分担来降低单关节峰值需求。
先确认该姿态是否真的必须，再决定是否为它加大模组。
