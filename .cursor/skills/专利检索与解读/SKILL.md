# 专利检索与技术方案解读

## 核心原则

1. **官方网站优先**：根据专利号前缀判断所属国家/地区，优先访问该国官方专利检索网站获取原文；官方网站因反爬/JS渲染/验证码等原因无法抓取时，才退回 Google Patents 等镜像站点作为补充信息来源。
2. **同族专利以申请人所在国原文为准**：若该专利存在海外同族（Also Published As / Family / 同族专利），且申请人/公司注册地与当前查到的语言版本不一致，应尽量找到**申请人公司注册所在国**的官方原文版本作为解读依据；其余语言版本仅作交叉验证，不作为主要解读来源（机器翻译的摘要/说明书容易有语义偏差，尤其是公司名称、专有名词的回译极易出错）。
3. **专有名词不做回译猜测**：申请人名称、代理机构、发明人等专有名词，只能照抄官方原文；不要用英文译名反推中文名（或反之）去"猜"，猜错的代价远大于多查一次官网。

## 工作流程

Task Progress:
- [ ] 1. 解析专利号，判断国家/地区代码
- [ ] 2. 查询该国官方专利检索网站
- [ ] 3. 检查同族专利、确定"原文语言"来源
- [ ] 4. 抓取原文全文（摘要+说明书+权利要求）
- [ ] 5. 按统一模板概述技术方案
- [ ] 6. 如用户提供官方数据库截图，逐字核对并纠正差异

### 步骤1：解析专利号确定国家/地区

常见专利号前缀与对应国家/地区、官方检索网站见 [官方专利数据库列表.md](官方专利数据库列表.md)。

### 步骤2：查询官方网站

- 优先用 `WebFetch` 直接抓取官方网站对应专利详情页；官方网站多数需要动态渲染/登录/验证码，若抓取失败（超时、空白、要求登录等），改用 `WebSearch` 搜索"专利号 + 官方网站名"寻找可读缓存，或退回 Google Patents（`https://patents.google.com/patent/<公开号>/<语言代码>`，如 `/zh`、`/en`、`/ja`、`/ko`）。
- Google Patents 页面通常会转载官方原文全文（尤其 CN/US/EP/JP/KR/WO），可作为官方原文的可靠替代来源，但**申请人/发明人等专有名词、法律状态日期，仍应尽量与官方网站或用户提供的官方截图核对**，不要只信任 Google Patents 的英文/机器翻译字段。

### 步骤3：处理同族专利

- 在 Google Patents 页面的 "Also Published As" / "Family Applications" / "Similar Documents" 区块，或官方网站的"同族专利/引证"标签页中查找同族成员。
- 确定申请人（Applicant/Assignee）的注册国家：
  - 若申请人注册国与当前找到的文本语言一致，直接以此为准。
  - 若不一致（例如某公司先在其本国申请、后有其他国家同族申请，但当前只抓到译文），应改为抓取**申请人注册国官方语言**的同族原文作为技术方案解读的主要依据，其他语言译文仅作参考对照，不作为最终结论来源。

### 步骤4-5：抓取原文并概述技术方案

抓取到全文（Abstract + Description + Claims）后，按以下结构输出概述：

```markdown
## 专利基本信息
- 专利号 / 申请号 / 申请日 / 公开(公告)日
- 申请人（原文照抄，不做回译）/ 发明人 / 分类号

## 要解决的问题
[背景技术中指出的痛点，简明列出]

## 技术方案（系统结构 / 方法流程）
[按硬件组成 + 工作流程/方法步骤分层描述，保留关键技术术语原文]

## 有益效果
[说明书总结的核心优势，末尾用一句话概括发明核心]
```

- 技术术语、部件命名尽量保留专利原文表述，不要意译替换。
- 若原文为外文，翻译时保留权利要求惯用语的准确含义（如"至少一个""其特征在于"等），避免过度意译丢失专利语言的严谨性。

### 步骤6：用户提供官方截图时的核对流程

用户经常会粘贴官方/商业专利数据库（如 CNIPA、PatSnap、incoPat、USPTO、Espacenet 等）的截图用于核对信息。此时：

1. 用 `Read` 工具打开图片，逐字核对每一个字段（申请号、申请日、公开号、公开日、申请人、发明人、代理人/代理机构、IPC/CPC分类、法律状态等）。
2. 逐项与此前提供的信息比对，**发现不一致要明确指出并更正**，不要含糊带过或回避。
3. 如果之前已经改错过一次，再次核对时要重新完整读图确认，不要凭记忆或再次猜测/回译，避免重复出错。
4. 更正说明中简要指出"错误来源"（如机器翻译回译、看错前一张图的文字），帮助用户理解为什么会出错，并给出最终确认版本。
