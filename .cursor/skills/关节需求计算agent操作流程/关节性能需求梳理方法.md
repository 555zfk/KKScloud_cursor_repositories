## 2. 数据结构说明

### 2.1 仿真 CSV 格式

```
time_s, torque_<关节列名>, vel_<关节列名>, ...
```

- 列前缀为 `torque_` 与 `vel_`，后接完整关节列名。
- 时间步长通常为 0.001 s（高采样频率）。
- **预处理时会忽略仿真起始 `START_T`（默认 0.5 s）**。

### 2.2 关节命名约定

以下为脚本默认列表（可按实际 URDF 修改）：

| 通用名 | 左侧列名后缀 | 右侧列名后缀 |
|--------|------------|------------|
| hip_pitch | left_hip_pitch_joint | right_hip_pitch_joint |
| hip_roll | left_hip_roll_joint | right_hip_roll_joint |
| hip_yaw | left_hip_yaw_joint | right_hip_yaw_joint |
| knee_pitch | left_knee_joint | right_knee_joint |
| ankle_pitch | left_ankle_pitch_joint | right_ankle_pitch_joint |
| ankle_roll | left_ankle_roll_joint | right_ankle_roll_joint |
| shoulder_pitch | left_shoulder_pitch_joint | right_shoulder_pitch_joint |
| shoulder_roll | left_shoulder_roll_joint | right_shoulder_roll_joint |

> 请根据仿真 CSV 中实际的列名逐一核对，格式为 `torque_<后缀>` 与 `vel_<后缀>`。

### 2.3 左右选取规则

所有脚本会自动选取**峰值功率更大的一侧**：

```python
def pick_side(df, jL, jR):
    pL = np.abs(df["torque_"+jL] * df["vel_"+jL]).values.max()
    pR = np.abs(df["torque_"+jR] * df["vel_"+jR]).values.max()
    return jL if pL >= pR else jR
```

### 2.4 重采样

```python
START_T = 0.5   # 忽略仿真前 N 秒
SAMPLE  = 0.02  # 重采样间隔(s)

def resample(df_raw, interval=SAMPLE):
    t   = df_raw["time_s"].values
    t_s = np.arange(t[0], t[-1], interval)
    idx = np.clip(np.searchsorted(t, t_s), 0, len(df_raw)-1)
    return df_raw.iloc[idx].reset_index(drop=True)
```

## 5. 需求 TN 曲线推导

**脚本：`plot_required_TN.py`**

### 5.1 思路

通过二分法找到最小 T_flat，使指定比例的仿真工作点落在梯形 TN 曲线包络之内。

### 5.2 USER CONFIG 关键项

```python
CSV_FILES  = { ... }      # 参与分析的工况（可只填一个）
JOINTS     = [ ... ]      # 参与分析的关节列表
TORQUE_SCALE = { ... }    # 各关节扭矩缩放

N_BASE    = 60.0   # RPM，额定转速（恒转矩段上限）
N_MAX     = 150.0  # RPM，最高转速
COV_CONT  = 0.85   # 连续工作区间覆盖率
COV_PEAK  = 0.98   # 短时工作区间覆盖率

TITLE = "关节需求 TN 曲线"   # 图表标题
```

### 5.3 TN 曲线模型（梯形）

```python
def tn_value(speed, T_flat, N_BASE, N_MAX):
    s = np.asarray(speed)
    return np.where(s <= N_BASE, T_flat,
           np.where(s <= N_MAX, T_flat*(N_MAX-s)/(N_MAX-N_BASE), 0.0))
```

```
扭矩
 │──────┐
 │ T_flat  ╲
 │          ╲
 └──────┬────┴──── RPM
    0  N_BASE    N_MAX
```

### 5.4 二分法求解

```python
def find_T_for_coverage(vel_all, tau_all, target, tol=1e-4):
    lo, hi = 0.0, tau_all.max() * 1.5
    for _ in range(80):
        mid = (lo + hi) / 2
        if np.mean(tau_all <= tn_value(vel_all, mid)) >= target:
            hi = mid
        else:
            lo = mid
        if hi - lo < tol: break
    return hi
```

### 5.5 功率计算

```python
P_cont = T_cont * N_BASE * 2 * np.pi / 60   # W，连续额定功率
P_peak = T_peak * N_BASE * 2 * np.pi / 60   # W，短时峰值功率
```

输出图中同时绘制合并散点、连续 TN 曲线（实线）与短时 TN 曲线（虚线），并在图例中标注对应的扭矩、覆盖率和功率。

## 6. 关节输入功率

**脚本：`plot_input_power.py`**

### 6.1 计算公式

```
P_out = |tau_motor| × |vel|       (W)
P_in  = P_out / η(|tau_motor|)
```

### 6.2 USER CONFIG 关键项

```python
EFF_TORQUE   = np.array([...])   # 从效率曲线图读取的扭矩点(Nm)
EFF_VALS     = np.array([...]) / 100.0   # 对应效率值(%)，转小数
EFF_LAM      = 1.2               # 平滑系数
EFF_MIN      = 0.03              # 效率下限（防止除以极小值）
STALL_TORQUE = 42.0              # 估算堵转扭矩(Nm)，用于超范围外推

# 若不同关节需要不同效率曲线：
EFF_OVERRIDE = {
    "ankle_pitch": {
        "torque": [...], "eff": [...],
        "lam": 0.8, "eff_min": 0.25, "stall": 13.5
    }
}
```

### 6.3 超范围外推逻辑

```python
# 数据范围内 → 取样条插值效率值
# 低于数据范围 → 用最小值
# 高于数据范围 → 线性外推至堵转扭矩处效率为0，取 EFF_MIN 作为下限
if hi.any():
    slope   = -eff_at_max / (STALL_TORQUE - eff_torque.max())
    eff[hi] = np.clip(eff_at_max + slope*(tau[hi]-eff_torque.max()),
                      EFF_MIN, eff_at_max)
```

### 6.4 输出内容

每个关节 × 每个工况输出一张四子图（扭矩/转速/效率/输入功率时间曲线），并在终端打印汇总表：

```
关节         工况      RMS输出(W)  RMS输入(W)  RMS清洁(W)  峰值输入(W)  饱和点
```

- `RMS清洁`：排除超出效率曲线范围（饱和）的采样点后重新计算的 RMS，用于避免外推误差影响评估。
- 饱和点在图中以橙色散点标出。

### 7.2 双侧累加逻辑

```python
for jname, jL, jR in JOINT_PAIRS:
    total = np.zeros(n)
    for jcol in [jL, jR]:         # 左右两侧都参与
        tau_m  = np.abs(df["torque_"+jcol].values) * scale
```

## 8. 电机选型分析

**脚本：`motor_selection_analysis.py`**

### 8.1 USER CONFIG 关键项

```python
# 电机选项库
MOTOR_SPECS = {
    "选项名称": {
        "rated_nm":  7.0,    # 额定扭矩(Nm)
        "rated_rpm": 60,     # 额定转速(RPM)
        "peak_nm":   20.0,   # 峰值扭矩(Nm)
        "peak_rpm":  120,    # 峰值转速(RPM)
        "color":     "#2563EB",
    },
    # 可添加任意数量选项
}

COV_CONT = 0.85   # 连续工作覆盖率
COV_PEAK = 0.98   # 短时工作覆盖率
```

### 8.2 选型判定

```python
def select_motor(T_cont, T_peak):
    for name, s in MOTOR_SPECS.items():
        if T_cont <= s["rated_nm"] and T_peak <= s["peak_nm"]:
            return name, "满足"
    return "超出所有选项", "需复核减速比"
```

按 `MOTOR_SPECS` 中定义的顺序依次判断，返回第一个同时满足连续/短时扭矩需求的电机选项。

### 8.3 功率计算

```python
P_rated = rated_nm  × rated_rpm  × 2π/60   # W
P_max   = peak_nm   × peak_rpm   × 2π/60   # W
```

### 8.4 输出内容

- 终端打印各关节的连续/短时扭矩需求、峰值转速、推荐选项与状态；
- 终端打印各电机选项的规格汇总（额定/峰值扭矩与功率）；
- 生成多子图对比图 `电机选型对比.png`：每个关节一张子图，叠加仿真散点、各候选电机的 TN 曲线，以及连续/短时需求水平线。

## 10. 整体流程图

```
仿真 CSV（多工况）
        │
        ├── scatter_abs.py
        │     └─ |扭矩| vs |速度(RPM)| → 散点 PNG + CSV（按工况分文件夹）
        │
        ├── plot_efficiency.py
        │     └─ 原始效率点 → smoothing spline → 平滑曲线 PNG + CSV
        │
        ├── plot_required_TN.py
        │     └─ 二分法求 T_flat（按覆盖率目标）→ 需求TN曲线 PNG
        │
        ├── plot_input_power.py
        │     └─ P_in = P_out / η(τ) → 各关节·各工况四子图 + RMS 功率表
        │
        ├── plot_total_power.py
        │     └─ 各关节双侧累加 → 堆叠面积图 + 合计功率曲线 → 全身RMS/峰值
        │
        └── motor_selection_analysis.py
              └─ T_cont/T_peak vs 电机额定/峰值 → 选型建议 + 对比图
```
